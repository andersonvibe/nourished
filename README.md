# Nourished

A food diary for steady weight loss: a calorie goal that fits you, filling-food balance, barcode and label scanning, weigh-ins with a forecast to your goal, exercise, meal plans, and well-rated recipes from what's in your kitchen.

Live app: https://andersonvibe.github.io/nourished/

- `index.html` is the whole app. `manifest.webmanifest`, `sw.js` and the icons let Chrome install it and open it offline.
- Your diary is stored in Chrome on your phone, not in this repository. Use **My goals → Save a backup file** now and then.
- Your Anthropic API key is stored only on your phone. Never put it in any file here.

Estimates only. Not medical or dietetic advice.
